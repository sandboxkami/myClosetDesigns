## 设计决定

- 当前版本：**v1.0**（2026-11-03）。按用户确认，鞋柜总宽按 **1700** 做，与琴柜平（手稿备注 1200 + 500 左右）；手稿最右侧 800 宽双列鞋架**不在本柜 1700 范围内**，视为另一面墙/后续柜体，本版不建模。
- 三段布局：左侧高柜 **408** + 中部鞋柜 **800** + 右侧开放鞋塔 **420**；4 块 18mm 竖板，总宽 = 408 + 800 + 420 + 4×18 = **1700**。
- 总高 **2303**，总深 **400**（门板 18 + 背板 12，净深 370）；顶部收口 30，踢脚 50。
- 左侧 408：自上而下 **包袋格 400 + 挂衣区 980 + 坐凳上空（余量，默认约 419）+ 抽拉换鞋凳 420**。换鞋凳宽 **300**、贴内侧（靠 408/800 分隔板），高 **420**，前伸 **500**，**无底、带轮**，可整体拉出。
- 中部 800：自上而下 **上柜 5 层（手稿 180 / 160 / 120 / 100 / 370，按可用高度等比缩放）+ 抽屉 120 + 开放鞋区 4 层（手稿 170 / 170 / 130 / 100）+ 底部开放区（约 413，含抽拉鞋板）**。中段下部鞋区做对开门；底部开放区不做门，日常拖鞋可直接取放。
- 右侧 420：**开放鞋塔 9 层**，上部 2 个 460 高靴位，中部 160 / 160（鞋盒），下部 230 / 175 / 130 / 130 / 130（鞋层，活动层板）。不做门。
- 门板：用户确认“混合”方案——左 408 上下两扇门（包袋格 + 挂衣区）、中 800 上柜对开门 + 下柜鞋区对开门 + 120 抽屉面板；全部平板、**无拉手、无反弹器**，门板延长留 3mm 缝，用指扣/门缝开合；420 窄柜保持开放。
- 颜色：门板/外框暖白，柜内/层板/背板暖木色；换鞋凳坐垫浅米色；示例物品只做预览道具。
- 关键尺寸可调；三段宽度中左 408、窄 420 固定，中段随总宽推导（默认 800）；中段/窄段层高按手稿比例随总高缩放。

## 尺寸（mm）

- 默认外形：宽 **1700** × 高 **2303** × 深 **400**。
- 宽度：左 408 + 中 800 + 窄 420 + 4 块 18 竖板 = 1700。
- 板厚：柜体/门板 18；背板 12；踢脚 50 高、前缩 50；顶部收口 30。
- 左侧 408：
  - 包袋格净高 400；挂衣区净高 980；坐凳上空默认约 419；换鞋凳高 420。
  - 换鞋凳：宽 300、深约 350（柜内净深 370）、高 420（含 30 坐垫）、前伸 500；凳体带 4 个小轮，柜内对应位置无底板。
  - 挂衣杆：位于挂衣区上部、距包袋格底板约 60，直径 25。
- 中部 800（默认总高下，按比例缩放后的参考值）：
  - 上柜 5 层约 **177 / 157 / 118 / 98 / 364**（原始 180 / 160 / 120 / 100 / 370）。
  - 抽屉高 120。
  - 开放鞋区 4 层约 **167 / 167 / 128 / 98**（原始 170 / 170 / 130 / 100）。
  - 底部开放区约 413，内置一块抽拉鞋板，板面距底部约 206，前伸约 300。
- 右侧 420（默认总高下）：
  - 9 层约 **462 / 462 / 161 / 161 / 231 / 176 / 131 / 131 / 131**（原始 460 / 460 / 160 / 160 / 230 / 175 / 130 / 130 / 130）。
  - 上部 2 层为靴位；下部 5 层为鞋层，其中 230 / 175 / 130 / 130 / 130 对应活动层板。
- 门板：
  - 左侧上门：包袋格，宽约 402，高约 423。
  - 左侧下门：挂衣区，宽约 402，高约 998。
  - 中部上柜对开：单扇宽约 395.5，高约 1008（含盖住上下层板边）。
  - 中部下柜对开：单扇宽约 395.5，高约 629（覆盖 4 层开放鞋区）。
  - 中部抽屉面板：宽约 794，高约 114。
  - 门缝 3；门板与外框齐平，无明装拉手。
- 页面可调：总宽、总高、总深、换鞋凳宽/高/前伸、板厚、踢脚高、顶部收口；中段宽、层高、门宽、凳体等自动推导。

## 现场约束

- 与琴柜平：手稿备注总长“1200 + 500 左右”，本版按 1700 做；现场需复尺确认琴柜完成面、墙面垂直度和收口关系。
- 鞋柜位置为入户换鞋区；背后/侧墙是否贴砖、是否有门套/踢脚线，需现场确认。
- 旧水电图在鞋柜位置标注五孔插座 ×2（离地约 300），本版**未开孔、未做检修口**；若插座在柜背后，需要在背板/柜体上开孔或改到开放区。
- 顶部是否有梁/吊顶、2303 是否为完成面净高，待现场复尺。
- 地面平整度影响带轮换鞋凳的抽拉；门槛/地砖收口待确认。

## 结构

- 三段柜体：左高柜 408、中鞋柜 800、右开放鞋塔 420；4 块 18mm 竖板（左右侧板 + 2 块分隔板）。
- 左侧 408：
  - 包袋格 400（上部开放或门后，本版做门）；下为挂衣区 980，装一根 25 挂衣杆。
  - 下部为坐凳上空 + 300 宽抽拉换鞋凳；柜内对应位置无底板，凳体带轮落地。
  - 上下两扇平板门，左侧铰链；门板盖住中间层板边，留 3 缝。
- 中部 800：
  - 上柜 5 层（鞋盒/包袋），两扇对开平板门。
  - 120 抽屉，整宽单抽，面板无拉手，指扣开合。
  - 开放鞋区 4 层，层板可调；下部对开平板门。
  - 底部开放区 + 抽拉鞋板（前伸约 300），不设门；底部踢脚 50 前缩 50。
- 右侧 420：
  - 开放鞋塔 9 层；上部 2 个 460 靴位，中部 2 个 160 鞋盒位，下部 5 个鞋层（230/175/130/130/130）。
  - 下部鞋层为活动层板，侧板排孔间距暂按 25/32 待定；本版不画排孔。
- 背板 12mm；顶板/底板/层板 18mm；开放区前沿与门板面相差 18（门板凸出）。
- 顶部 30 收口板；中部/右侧踢脚 50；左侧换鞋凳区无底、无踢脚。

## 材质与颜色

- 门板/外框/踢脚：哑光暖白。
- 柜内/层板/背板/挂衣杆：暖木色木纹。
- 换鞋凳坐垫：浅米色织物；凳体暖白；小轮深色金属/尼龙。
- 拉手：无明装拉手；门板指扣/门缝，抽屉指扣。
- 示例物品：包、挂衣、鞋盒、鞋/靴、坐垫（仅预览道具，不属于柜体）。

## 交互

- OrbitControls：旋转、缩放、平移；限制视角不钻到地面以下。
- 点击门板开合；左侧上下门、中部上柜对开门、中部下柜对开门均可独立开合。
- 点击 120 抽屉拉出；点击抽拉换鞋凳拉出 500；点击中部底部抽拉鞋板拉出约 300。
- “全部打开/关闭”“重置视角”“恢复默认尺寸”。
- 切换“显示尺寸”“显示示例物品”“显示门板”；关闭门板后可直接查看内部层板。
- 左侧面板调整总宽/总高/总深/换鞋凳尺寸/板厚/踢脚/顶部收口，模型实时重建。
- 尺寸标注显示整体宽/高/深；面板显示三段宽度、左侧分区、中部层高、窄柜 9 层高度。
