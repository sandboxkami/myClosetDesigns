## 设计决定

- 当前版本：**v1.1**（2026-11-03）。在 v1.0 三段 1700 宽鞋柜基础上，按新增参考图增加**前后双层**：前层保持 400 深，后层 350 深；后层只做在右侧 420 窄塔后面，做成 **350 宽 × 350 深 × 通高 2303** 的侧抽鞋架，向右侧拉出约 400。
- 总宽仍为 **1700**（与琴柜平，手稿备注 1200 + 500 左右）；三段 **408 + 800 + 420**，4 块 18mm 竖板。
- 总高 **2303**；总深变为 **750**（前层 400 + 后层 350）；前层净深 370；后层净深约 338。
- 前层结构沿用 v1.0：左 408 包袋格 400 + 挂衣区 980 + 坐凳上空 + 抽拉换鞋凳 420；中 800 上柜 5 层 + 120 抽屉 + 开放鞋区 4 层 + 底部抽拉鞋板；窄 420 开放 9 层。
- 后层鞋架：右侧 420 窄塔后，**350 宽**（也可在页面调到 420），白色柜体，10 层，层高按参考 **340 / 340 / 220×4 / 150×3 / 100** 等比缩放；右侧板装金属拉手，整体向右抽出；前层窄塔保持开放，后层藏在窄塔背板后。
- 3D 用**台阶墙 / 凹龛**表现后层：左侧和中部前层背板贴 400 深墙面；右侧后层占 350 深凹位。现场若没有 350 深凹位，需要改成柜体加深/另做收口，见“待确认”。
- 前层门板仍为平板、**无拉手、无反弹器**，门板延长留 3mm 缝；后层鞋架使用**右侧拉手**（抽拉功能件，不是前门明装拉手）。
- 颜色：前层门板/外框暖白，柜内/层板/背板暖木色；后层鞋架整体暖白（参考图为白色隐藏柜）；换鞋凳坐垫浅米色。
- 关键尺寸可调；左 408、窄 420 固定；中段宽随总宽推导；后层深/宽/抽拉、前层总深可调；各层高按比例随总高缩放。

## 尺寸（mm）

- 默认外形：宽 **1700** × 高 **2303** × 深 **750**；前层 **400** 深，后层 **350** 深。
- 宽度：左 408 + 中 800 + 窄 420 + 4 块 18 竖板 = 1700。
- 后层鞋架：宽 **350**、深 **350**、高 **2303**；净宽约 314、净深约 338；向右侧抽拉 **400**。
- 板厚：柜体/门板 18；背板 12；踢脚 50 高、前缩 50；顶部收口 30。
- 左侧 408：
  - 包袋格净高 400；挂衣区净高 980；坐凳上空默认约 419；换鞋凳高 420。
  - 换鞋凳：宽 300、深约 350（前层柜内净深 370）、高 420（含 30 坐垫）、前伸 500；凳体带 4 个小轮，柜内对应位置无底板。
  - 挂衣杆：位于挂衣区上部、距包袋格底板约 60，直径 25。
- 中部 800（默认总高下，按比例缩放后的参考值）：
  - 上柜 5 层约 **177 / 157 / 118 / 98 / 364**（原始 180 / 160 / 120 / 100 / 370）。
  - 抽屉高 120。
  - 开放鞋区 4 层约 **167 / 167 / 128 / 98**（原始 170 / 170 / 130 / 100）。
  - 底部开放区约 413，内置一块抽拉鞋板，板面距底部约 206，前伸约 300。
- 右侧 420 前层：
  - 9 层约 **462 / 462 / 161 / 161 / 231 / 176 / 131 / 131 / 131**（原始 460 / 460 / 160 / 160 / 230 / 175 / 130 / 130 / 130）。
  - 上部 2 层为靴位；下部 5 层为鞋层，其中 230 / 175 / 130 / 130 / 130 对应活动层板。
- 后层 350 宽鞋架（默认总高下）：
  - 10 层约 **334 / 334 / 216 / 216 / 216 / 216 / 148 / 148 / 148 / 98**（原始 340 / 340 / 220×4 / 150×3 / 100）。

- 门板：
  - 左侧上门：包袋格，宽约 402，高约 423。
  - 左侧下门：挂衣区，宽约 402，高约 1007（下沿盖住坐凳上空上方层板）。
  - 中部上柜对开：单扇宽约 395.5，高约 1018（下沿盖住抽屉上方层板）。
  - 中部下柜对开：单扇宽约 395.5，高约 650（上沿盖住抽屉下方层板，下沿盖住底部开放区上方层板）。
  - 中部抽屉面板：宽约 794，高约 117。
  - 门缝 3；前层门板与外框齐平，无明装拉手；后层鞋架右侧金属拉手约 120 高。
- 页面可调：总宽、总高、总深、后层深、后层宽、后层抽拉、换鞋凳宽/高/前伸、板厚、踢脚高、顶部收口；中段宽、前层深、层高、门宽、后层净高等自动推导。

## 现场约束

- **后层凹位**：后层只做右侧窄塔后，占用约 350 深；3D 用台阶墙/凹龛表现。现场需确认右侧墙面是否有 350 深凹位，或是否接受柜体在该段加深/现场收口。
- **右侧抽拉净空**：后层鞋架向右抽出约 400，右侧需留约 400 以上净空；注意推拉门、门套、墙面和走道。
- 与琴柜平：手稿备注总长“1200 + 500 左右”，本版按 1700 做；现场需复尺确认琴柜完成面、墙面垂直度和收口关系。
- 鞋柜位置为入户换鞋区；背后/侧墙是否贴砖、是否有门套/踢脚线，需现场确认。
- 旧水电图在鞋柜位置标注五孔插座 ×2（离地约 300），本版**未开孔、未做检修口**；若插座在柜背后，需要在背板/柜体上开孔或改到开放区。
- 顶部是否有梁/吊顶、2303 是否为完成面净高，待现场复尺。
- 地面平整度影响带轮换鞋凳和后层鞋架的抽拉；门槛/地砖收口待确认。

## 结构

- 前层三段：左高柜 408、中鞋柜 800、右开放鞋塔 420；4 块 18mm 竖板（左右侧板 + 2 块分隔板）；前层深 400。
- 后层：右侧窄塔后独立 350 宽 × 350 深 × 2303 高白色鞋架；左右侧板、顶板、底板、背板、10 层（9 块内部层板 + 顶/底）；右侧板装金属拉手；整体向右侧抽出。
- 左 408：包袋格 400 + 挂衣区 980 + 坐凳上空 + 300 宽抽拉换鞋凳；柜内对应位置无底板，凳体带轮落地；上下两扇平板门，左侧铰链，门板盖住中间层板边，留 3 缝。
- 中 800：上柜 5 层（鞋盒/包袋），两扇对开平板门；120 抽屉，整宽单抽，面板无拉手，指扣开合；开放鞋区 4 层，层板可调；下部对开平板门；底部开放区 + 抽拉鞋板（前伸约 300），不设门；底部踢脚 50 前缩 50。
- 右 420 前层：开放鞋塔 9 层；上部 2 个 460 靴位，中部 2 个 160 鞋盒位，下部 5 个鞋层（230/175/130/130/130）；下部鞋层为活动层板，侧板排孔间距暂按 25/32 待定；本版不画排孔。
- 后层鞋架：白色柜体，10 层；顶/底 + 9 块内部层板；右侧拉手；向右侧抽拉；前层窄塔背板挡住后层，拉出后从右侧取鞋。
- 3D 台阶墙：左侧/中部前层背板贴 400 深墙面；右侧后层占 350 深凹龛；后层鞋架在凹龛内向右滑出。
- 背板 12mm；顶板/底板/层板 18mm；前层开放区前沿与门板面相差 18（门板凸出）；顶部 30 收口板；中部/右侧踢脚 50；左侧换鞋凳区无底、无踢脚。

## 材质与颜色

- 前层门板/外框/踢脚：哑光暖白。
- 前层柜内/层板/背板/挂衣杆：暖木色木纹。
- 后层鞋架：整体暖白柜体/层板/背板（参考图隐藏柜为白色）；右侧金属拉手。
- 换鞋凳坐垫：浅米色织物；凳体暖白；小轮深色金属/尼龙。
- 前层拉手：无明装拉手；门板指扣/门缝，抽屉指扣。后层为抽拉功能，使用右侧拉手。
- 示例物品：包、挂衣、鞋盒、鞋/靴、坐垫（仅预览道具，不属于柜体）。

## 交互

- OrbitControls：旋转、缩放、平移；限制视角不钻到地面以下。
- 点击前层门板开合；左侧上下门、中部上柜对开门、中部下柜对开门均可独立开合。
- 点击 120 抽屉拉出；点击抽拉换鞋凳拉出 500；点击中部底部抽拉鞋板拉出约 300。
- 点击后层鞋架/右侧拉手，向右侧拉出约 400；再点收回。
- “全部打开/关闭”“重置视角”“恢复默认尺寸”。
- 切换“显示尺寸”“显示示例物品”“显示门板”；关闭门板后可直接查看内部层板。
- 左侧面板调整总宽/总高/总深/后层深/后层宽/后层抽拉/换鞋凳尺寸/板厚/踢脚/顶部收口，模型实时重建。
- 尺寸标注显示整体宽/高/深；面板显示三段宽度、前/后层深、左侧分区、中部层高、窄柜 9 层、后层 10 层高度。

## 待确认

- [ ] 现场复尺：1700 是否确为与琴柜平的总宽；1200 + 500 的具体起止点。
- [ ] **后层凹位**：右侧墙面是否有 350 深凹位；若没有，是柜体加深、做假墙/收口，还是取消后层。
- [ ] **右侧抽拉净空**：后层向右抽出约 400，是否会被推拉门/门套/走道挡住；拉手高度和方向是否顺手。
- [ ] 后层鞋架宽度：本版 350（参考图），是否改为 420 与窄塔同宽；两种都能在页面调。
- [ ] 后层通高 2303 是否符合使用习惯；参考图“900”只是下部标注，是否要改为只做下部 900 高。
- [ ] 后层白色柜体是否与现场风格一致；是否改木色/与窄塔一致；金属拉手款式。
- [ ] 后层鞋架的滑轨/承重/防倾倒；抽出后重心和固定方式。
- [ ] 后层鞋架与前层窄塔背板的间隙、密封、防尘；后层拉出时是否与前层门板/拉手干涉。
- [ ] 手稿最右侧 800 宽双列鞋架是否另做在另一面墙；本版未包含。
- [ ] 左侧包袋格是否保留门板，还是做开放壁龛；本版按上下两扇门。
- [ ] 换鞋凳 300 宽是否够用；凳体内部是否需要鞋层/抽屉；轮子规格、承重、刹车。
- [ ] 中部下柜门是否覆盖开放鞋区；若日常鞋想开放，可去掉下柜门。
- [ ] 中部 120 抽屉是否做一整宽单抽，还是按参考图分 2–3 个抽屉；本版做整宽单抽。
- [ ] 踢脚高度 50、顶部收口 30、门缝 3、板厚 18 是否按报价/厂家标准调整。
- [ ] 活动层板数量/位置：中段鞋区 3 块、窄柜下部 4 块、后层 9 块；排孔间距 25 还是 32。
- [ ] 手稿“此层板前端缩进 5cm”具体指哪块层板（中段底部鞋层/抽拉板上方）；本版未做前缩，待确认后调整。
- [ ] 鞋柜位置五孔插座 ×2（离地 300）是否在柜内开孔/留检修口。
- [ ] 无拉手门板的指扣形式（45° 斜边/门缝留指/反弹器禁用）。
- [ ] 左侧下门高约 1007、中部上柜门高约 1018，是否需要加厚/拉直器；铰链数量与承重。
- [ ] 柜体与墙面、门套、踢脚线、地面的收口；是否需要见光板/收口条。
- [ ] 门板/柜体色号、封边、五金品牌；ENF 板材与 18mm 柜体/7mm 背板是否按报价澄清清单执行。
