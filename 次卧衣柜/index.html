设计要点

  • 外观 白色平板门 + 木色内胆 + 小圆木拉手。
  • 左侧 乐高 / 模型 / 故事书展示格；一扇通高白色平板门，取消玻璃门和拱形开口。
  • 中区 长衣挂区两扇门从中间对开；固定上杆 + 高度可调的活动下杆（侧板滑槽），也可改为收纳盒；下方 2 个叠放抽屉。
  • 右区 短衣挂区 + 水平层板 + 树屋开口；短衣区底抽改为与中间单抽同高（约 202.5），树屋开口随之下移，两扇梯形门向下延长，门拉手回到正常高度。
  • 顶柜 5 门：1 扇与展示格同宽；2/3、4/5 分别从中间向两边开。
  • 拉手 展示柜、长衣区、短衣区门拉手距地 1000；短衣区梯形门拉手与其他门一致，距门缝约 60。
  • 交互修复 切换“活动挂衣架/收纳盒”或调整活动杆高度时会重建柜体；现在重建前保存已开门/抽屉状态，重建后恢复，不再自动复位。

v1.4 新增双块决策看板与“关键约束聚焦”手动分步巡游：9 处关键尺寸/比例/结构逐点拉近，用“上一步 / 下一步 / 结束浏览”自己控制节奏，不再自动计时、不锁定面板；尺寸用延伸线 + 尺寸线 + 斜刻度标注，标签落在标注线上。v1.3 的 2200×2400×600 固定、短衣底抽同中抽、树屋开口下移、拉手 1000 均保留。
