## 尺寸（mm）
- 原图单位：mm。
- 外形：宽 **2900** × 高 **2340** × 深 **300**。
- 总高：底座 **600** + 主柜 **1740**（5 层 × 348，348 含层板厚度）= **2340**。
- 板厚：柜体 **18**（默认，待确认）；背板 **9**（默认，待确认）。

### 底座（600 高）
- **7 列**，从左到右：**400 / 400 / 400 / 500 / 400 / 400 / 400**。
- 中间第 4 列 **500**，比其余列稍宽；这一列的**左右两块侧板各开 1 个 ⌀60 过线孔**。
- 中间列背面留插座位（3D 用一块小面板示意）；底部 7 格开放，放收纳筐。
- 底座顶面在 600 高处，作为主柜的第一层搁板；左侧猫踏步区对应的 550–800 缺口保留，猫可从底座进入猫踏步。

### 主柜（600–2340，5 层 × 348）
- 主柜不再按 7 列分，改为 **4 个区**：
  - **左侧猫踏步区 800 宽**：550 宽层板上下左右交错，错位约 **232**；
  - **中间两列各 700 宽**：普通开放层板；
  - **右侧猫洞列 700 宽**：每层一块带 ⌀220 洞的层板。
- 主柜竖板位置：**800 / 1500 / 2200**；左右外框为 0 和 2900。
- 主柜层板高度：**600 / 948 / 1296 / 1644 / 1992**；顶板 2340。
- 主柜全开放，不做门、不做电视龛；电视已改用移动支架。

## 猫通道
- **左侧猫踏步**：主柜左侧 800 宽区域，5 块 550 宽层板，按“左 / 右 / 左 / 右 / 左”交错；默认错位约 232（= 左区 800 − 550 − 18 板厚）。猫可从底座 600 逐级跳上。
- **右侧猫洞**：主柜右侧 700 宽列，5 块层板各开 1 个 ⌀220 圆洞；洞心在列宽方向按手稿**错落**布置，不排成一条竖直线。默认洞心比例（从下到上）：**0.30 / 0.70 / 0.40 / 0.66 / 0.48**；对应距该列左边界约 **210 / 490 / 280 / 462 / 336**。最小净边约 **82**。
- 猫洞边缘做封边/圆角，避免毛刺；3D 用圆洞 + 深色洞缘表示。

## 现场约束
- 墙面：整柜靠平墙，柜深 300；左侧靠墙，右侧为通道。
- 空调吊顶：左上方约 550 深 × 380 高，柜顶按 2340 收口，不与吊顶冲突。
- **50 管开口**：手稿注明保留，背板做开口；本版在背板右上靠后位置留 ⌀50 孔（位置待现场确认）。
- **过线孔**：底座中间 500 列的两块侧板各留 1 个 ⌀60 孔，靠近底座顶部（约在 600 顶面下 120），用于走电线/插座；具体高度和前后位置待现场确认。
- 插座/管线：电视已移走，仍需保留插座和走线；背板开孔后避让。
- 移门：手稿顶部有“移门”标注；经确认上柜全开放，本版不做门，移门视为相邻空间/吊顶构件，不计入本柜。

## 结构
- 底座：7 列 × 600 高开放格；中间 500 列两侧板开 ⌀60 孔；底座顶面为主柜第一层搁板。
- 主柜：4 区（800 猫踏步 + 700 + 700 中间列 + 700 猫洞列）；5 层；顶板、侧板、背板完整。
- 主柜竖板：800 / 1500 / 2200；底座竖板：400 / 800 / 1200 / 1700 / 2100 / 2500。
- 底座与主柜在 800 处竖板对齐；1500 / 2200 为主柜新增竖板，坐在 600 顶面上。
- 左猫踏步：5 块 550 宽 × 300 深 × 18 厚层板，左右交错。
- 右猫洞：5 块 700 列层板，每块 ⌀220 洞，洞心错落。
- 无门、无抽屉、无踢脚线；柜体直接落地。

## 材质与颜色
- 外框/侧板/顶底板：暖白（默认，待确认）。
- 层板/竖板/猫踏步：暖木色（默认，待确认）；猫踏步用浅木色区分。
- 背板：暖白（默认，待确认）。
- 猫洞洞缘：深木色圆环；过线孔洞缘：浅金属色圆环。
- 底座收纳筐：藤编色；猫道具：暖灰/奶油色。
- 实际板材/颜色以用户确认后的 md 为准。
